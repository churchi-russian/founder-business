Configurar API

Esta ferramenta usa a Places API (New) do Google, direto do navegador — não há servidor por trás. Você precisa da sua própria chave.

1. Crie um projeto no Google Cloud Console e ative a fatura (a API tem uso pago acima da cota gratuita).
2. Ative a "Places API (New)" em APIs e Serviços.
3. Crie uma chave em Credenciais e restrinja por referenciador HTTP ao domínio do seu GitHub Pages (ex: seuusuario.github.io/*) para não deixá-la aberta.
